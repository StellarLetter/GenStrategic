# RULES — 规则事实源（唯一权威）

本文件是**唯一规则来源**。代码、测试、文档不得自行猜测或扩展规则。
凡推导不出的处理逻辑或自相矛盾之处，一律以本文 §附录 A 的**用户裁决**为准；
裁决之外的规则空白属于**待澄清**，禁止私自裁决（见 §附录 B）。

编号约定：`R<n>` 为规则条目，代码注释与测试名直接引用这些编号。

---

## 1. 回合 Turn / 刻 Tick

| 编号 | 规则 |
| --- | --- |
| R1.1 | 一回合 = 1 秒，分上下两个半回合：`Turn N`（上半回合）与 `Turn N.`（下半回合）。半回合又称**刻（Tick）**。 |
| R1.2 | 游戏开局为 `Turn 0`；刻序为 `Turn 0`, `Turn 0.`, `Turn 1`, `Turn 1.`, … |
| R1.3 | 每个刻结束时触发一次结算（R7.1）。刻长 1 秒 ⇒ 1 秒 2 刻。 |

## 2. 地图

| 编号 | 规则 |
| --- | --- |
| R2.1 | 地图是正方形地块构成的二维矩形（`size × size`）。地块索引 `index = row * size + col`。 |
| R2.2 | 地块类型（地形）：**首都**、**平原**、**山地**、**超市**。 |

## 3. 兵力与控制

| 编号 | 规则 |
| --- | --- |
| R3.1 | 每个地块拥有兵力值，兵力属于该地块的控制者。 |
| R3.2 | 每名玩家初始控制自己的首都，首都初始兵力 **1**；其它地块开局无控制者（中立）。 |
| R3.3 | 城市（首都/超市）初始有 **40–50** 的中立兵力。 |
| R3.4 | 被非中立势力控制时，**Turn N. 结算**（见 R3.7）执行增长：首都与城市 **+1 兵力**；平原**每 25 回合 +1 兵力**（第一次刷新在 `Turn 25.`）。 |
| R3.5 | **视野** = 自己控制的全部地块 ⊕ 与其 8 相邻（含斜角）的地块，这些地块给出完整信息（含兵量）。 |
| R3.6 | 视野外地块不给兵量，但可识别它**是否为首都转化型城市**（R5.4）。 |
| R3.7 | 每个整回合（Turn N.）结算一次增长；`Turn N`（上半回合）不结算增长。 |

## 4. 移动与战斗

| 编号 | 规则 |
| --- | --- |
| R4.1 | 调兵请求 = `(起点, 方向, 比例)`。方向 ∈ {上,下,左,右}（**4 相邻**）。不可向山地状态的地块调兵（R4.9）。 |
| R4.2 | 实际移动兵力 = `min(ceil(起点当刻兵力 × 比例), 起点当刻兵力 − 1)`，且 `≥ 0`。允许发起 0 兵力的请求。 |
| R4.3 | **阵地战**：目标地块存在非友方兵力（含移动到该地块的兵力）时，参战各方按阵营求和后互减；最大者获胜，剩余 = 最大 − 次大；**并列最大者全部归零、且不占领**。 |
| R4.4 | 攻占：战斗后（或无战斗）目标地块到达兵力 `> 0` 即立刻被到达方占领。 |
| R4.5 | **遭遇战**：“根据请求发起调兵”结算完成后，**互为出发地和目标**的调兵请求（A→B 与 B→A）触发。双方在途经空间抵消，**胜方剩余兵力继续前往各自目标**（R7.2 第 3 步完成该剩余移动）。 |
| R4.6 | 己方/中立地块：目标势力为友方时，`目标兵力 = 原兵力 + 到达兵力`（累加，**不设上限**）。 |
| R4.7 | 每名玩家每个 Tick 只处理 **1 条**调兵请求（调兵链 FIFO 弹出 1 条）。 |
| R4.8 | 同一地块在单个 Tick 内最多发出 1 次调兵（R4.7 的直接结果；见附录 A）。 |
| R4.9 | “山地状态的地块”= 地形为山地，或已失去视野的未知地形地块（客户端/服务端的可见地形）。服务端以**真实地形**判定（山地 = 不可通行），客户端以**可见地形**渲染。 |

## 5. 首都与停止抵抗

| 编号 | 规则 |
| --- | --- |
| R5.1 | 每名玩家有且仅有一座**王城**（首都）。 |
| R5.2 | 攻占他人王城：占领其**全部领土**，每块地继承 `max(floor(原兵力 / 2), 1)` 兵力，控制者 = 攻占方；地形与增长规则不变。 |
| R5.3 | **停止抵抗**：回合结算阶段结束时，没有任何控制地块的玩家立刻出局；其首都转化为**普通城市**。 |
| R5.4 | 首都转化型城市（R5.3 产生的城市）：逻辑上等同普通城市，唯一区别是**视野外渲染为平原**（普通城市在视野外渲染为山地）。 |
| R5.5 | **投降**：玩家主动放弃并退出，进入 **40 Tick 过渡期**。过渡期内其地块仍属本人、仍按 R3.4 增长、仍会被攻打与参与战斗，仅**不能操作**（调兵链在投降瞬间清空）。过渡期结束后其**全部地块同时转为中立**，兵力完整保留；首都转化为首都转化型城市（R5.4），转化逻辑同 R5.3。 |

## 6. 操控与 UI

| 编号 | 规则 |
| --- | --- |
| R6.1 | 点击可选中一个地块。 |
| R6.2 | `W`/`S`/`A`/`D` 向相邻地块调兵，并**选中对应地块**。 |
| R6.3 | 调兵链：缓存多个调兵请求，后端按 **FIFO** 在每 Tick 结束时结算（每 Tick 弹 1 条，R4.7）。 |
| R6.4 | `Q` 取消完整调兵链；`E` 取消最新调兵请求。 |
| R6.5 | **点击调兵**（可开关）：点击已选中地块的相邻地块时触发一次调兵。点击调兵与键盘调兵**处理逻辑相同**。 |
| R6.6 | 调兵比例：选中新地块 → 100%；再次点击当前选中地块 → 50%；`+`/`-` 调整比例（步长 10%，范围 10%–100%）。 |
| R6.7 | 每个请求**各自记录入队时的比例**。 |
| R6.8 | 面板展示每名玩家的**兵力总和**（Army）与**控制区大小**（Land = 控制地块数，含首都与城市）。 |
| R6.9 | 视野外渲染：山峰与城市 → 山地外观；其它（平原/首都）→ 平原外观；首都转化型城市 → 平原外观（R5.4）。视野内按真实地形 + 控制色 + 兵量渲染。 |

## 7. 回合结算

| 编号 | 规则 |
| --- | --- |
| R7.1 | 结算顺序：**兵力增长 → 根据请求发起调兵 → 结算遭遇战 → 结算阵地战 → 更新占领 → 检查停止抵抗**。 |
| R7.2 | “根据请求发起调兵”（第 2 步，原子阶段）：每玩家 FIFO 弹出 1 条请求，按 R4.2 计算实际兵力并从起点扣除，生成“飞行中兵力 `(来源, 方向, 兵力)`”；**此刻不更新任何占领**。第 3 步：互为出发/目标的请求做遭遇战抵消，胜方剩余兵力继续飞向目标（R4.5）。 |
| R7.3 | **对称一致原则**：不产生任何随机结果；同一状态对每一方给出相同结算。所有集合遍历必须按 `(势力/玩家 id, 地块 index)` 排序，禁止依赖字典插入序。 |
| R7.4 | 只剩一名拥有地块的玩家时游戏立即结束。 |

## 附录 A — 用户裁决（澄清记录）

> 以下条目全部来自用户澄清，**优先级高于规则原文中的字面歧义**。

| 编号 | 议题 | 裁决 |
| --- | --- | --- |
| C-01 | 增长时机 | 在 `Turn N.` 结算；`Turn N` 不增长（每整回合一次）。平原首次刷新在 `Turn 25.`。 |
| C-02 | 调兵量 | `min(ceil(兵力×比例), 兵力−1)`；**允许发起 0 兵力请求**。比例默认 100%，再点当前地块 → 50%，`+`/`-` 微调（10% 步长）。 |
| C-03 | 相邻语义 | **除非明确写“8 相邻”，相邻均指 4 相邻**。一个地块只能由一方控制。视野（R3.5）明确为 8 相邻，保留。 |
| C-04 | 遭遇战触发 | “根据请求发起调兵”结算完成后，**互为出发地和目标地块**的请求触发遭遇战；胜方剩余兵力继续前往目标。 |
| C-05 | 每 Tick 调兵条数 | 每玩家每 Tick 只处理 1 条请求（即每秒最多 2 条）。 |
| C-06 | 比例归属 | 每个请求各自记录入队时的比例。 |
| C-07 | 取整 | 向上取整（`ceil`），随后限制在 `[0, 兵力−1]`。 |
| C-08 | 投降过渡期 | 40 Tick 内逻辑不变（仍增长、仍参战），仅不能操作；投降瞬间清空调兵链。期满全部地块转中立、兵力完整保留。 |
| C-09 | 首都转化 | 出局/投降产生的首都都转为**首都转化型城市**：逻辑同普通城市，视野外渲染为平原。 |
| C-10 | 遭遇战与阵地战顺序 | 本 Tick 所有请求先统一判对穿遭遇战并抵消，剩余兵力再集体进入阵地战。 |
| C-11 | 王城继承 | 被继承的领土保留地形与城市/平原身份及增长规则，只换控制者。 |
| C-12 | 结束条件 | 只剩一名有地玩家时立即结束。 |
| C-13 | 攻占后的兵力可见性 | 防守方从面板/视野中立即看到该地块兵力为 0（战败后）。 |
| C-14 | 己方合并 | 到达友方（含自己）地块时兵力累加，不设上限。 |
| C-15 | 兵力上限 | 无上限。 |
| C-16 | Land 统计 | 控制地块数（含首都与城市）。 |
| C-17 | 视野外城市识别 | 视野外**全部城市**（除首都转化型城市）都渲染为山地；首都转化型城市渲染为平原。 |
| C-18 | 三方遭遇战 | 4 相邻语义下遭遇战只可能双方触发，无需三方逻辑。 |
