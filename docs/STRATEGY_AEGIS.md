# STRATEGY — `ai/aegis.py`：1v1 攻坚策略

> 规则以 [`RULES.md`](RULES.md) 为唯一事实源；本文件只说明**策略怎么打**、**为什么这么打**。
> 数据结构与接入手册见 [`AI_API.md`](AI_API.md)。

## 1. 一句话

**先把地占满（地几乎免费、且是长期兵源），顺手吃近城（+1 兵/回合），把最厚的一股兵朝对手王城
推过去，抵近后一击斩首；王城若已毁就逐个拔点。**

## 2. 从规则推出的三条结论

| 结论 | 依据 | 对策略的含义 |
| --- | --- | --- |
| **占地是最便宜的兵源** | 平原每 25 回合 +1 兵（R3.4）；占地只要 1 兵，且这 1 兵仍留在该格（R4.4/R4.6，不算损失） | 能占就占：200 格 ≈ 8 兵/回合，接近 8 座城市 |
| **城市是"付费"兵源** | 中立城 40–50 兵（R3.3），攻打按 R4.3 互减，净损失 ≈ 驻军；换来 +1 兵/回合 | 只拿"打得起、够得着"的城（约 45 回合回本），不为它拆散主力 |
| **调兵预算 = 1 条/刻** | R4.7；每格最多送 `army-1`（R4.2），一股兵每走一格掉 1 | 必须让"最厚的一股"去干最值钱的事：所有选择都按"能搬多少兵"加权 |

终局只有一个目标：**把一支比对手王城守军更厚的兵送到其邻格**（R5.2 攻陷即继承全部领土 ⇒
R5.3 出局）。距离本身是成本，所以推进 = 一边占地一边把兵往前挪。

## 3. 每 Tick 的决策流水线

`act(obs)` 按优先级**只返回一条** `move`（或 `None`）：

| 优先级 | 模式 | 触发条件 | 动作 |
| --- | --- | --- | --- |
| 1 | `defend` | 王城 `DEFEND_RADIUS` 内可见敌兵合计 > 本城守军 + 余量 | 全部兵力向王城汇聚（该模式下不保留留守） |
| 2 | `kill` | 对手王城可见，且我方邻格一次能压过其守军 | 直接攻陷 —— 一击结束对局 |
| 3 | `city` | 某可见城市的邻格能一次压过其驻军 | 拿城（对手的城额外优先，顺带削其收入） |
| 4 | `chip` | 总兵力 > 对手总兵力 × `CHIP_RATIO`，且单次能磨掉守军 `CHIP_FRACTION` 以上 | 用"打不过也磨"换血（R4.3 互减，我兵多则换得起） |
| 5 | `push` | `my_total > their_total×系数 + 到王城距离 + 余量` | 沿己方/空地通路把兵推向王城（允许进迷雾） |
| 6 | `expand` | 有相邻的"非己方、可通行、打得过"的格 | 占地：城市 > 空地 > 敌方地块 > 迷雾，同类取更近目标者 |
| 7 | `flow` | 被己方/山地围住 | 沿己方通路向目标补兵 |

**目标选择**（`_goal`）依序：对手已残（`ecap_dead` 或地块 ≤ `MOPUP_LAND`）→ 最近的敌方地块
（逐个拔点）；否则能压死就越王城；否则挑一个"打得起、距离 ≤ `CITY_GOAL_STEPS`"的城；否则对手
王城；最后退化为"最远的可达非山地"。

### 3.1 关键细节（都是踩过的坑）

* **空地判定**：只认"看得见（`army is not None`）+ 无主 + 0 兵"。视野外 `owner` 也是 `None`
  （R3.6），把迷雾当空地会一头撞进守军/山地。
* **不可通行**：视野内 `terrain == 2` 是山（R4.9）；**视野外的普通城市也渲染成 2**（R6.9），
  所以一律按不可通行处理。
* **打架只在必胜时**：`到达兵力 > 守军`（R4.3 并列最大双方归零且不占领）；唯一例外是
  `chip` 模式的"换血"。
* **落点优先级**：行军时优先"直接落到目标格"（`FLOW_FINISH`），否则会出现"最厚的兵一直在
  附近绕圈、却没人去拿眼前那格"的假推进。
* **不走回头路**：记住上一步的 `(src, dst)`，下一步不许原路退回，防止两格之间来回震荡。
* **王城留守**：平时少留兵（不拖慢进攻），一旦附近出现敌兵就按"敌兵合计 + 余量"抬高留守，
  上限 `CAP_RESERVE_MAX` —— 这是被对手单股偷袭后补上的。
* **对手王城被毁的识别**：攻陷王城后该格会变成"首都转化型城市"（R5.4，视野里 `terrain == 4`），
  或直接归我（R5.2）。识别到就清掉目标，否则会一直朝一座不存在的王城推进。
  （同刻对手反击抢回地块时，王城可能先被毁、对手仍有地，此时只能逐个拔点。）
* **王城候选先验**：迷雾里 `terrain == 2` = 山或普通城市，`0` = 平原/王城/转化城（R6.9）；
  王城周围 2 格禁山（R2.7），所以"以某格为中心的 5×5 全非山"几乎只可能出现在王城保护圈。
  它只用于**推进方向的软先验**（且要求曼哈顿距离 ≥12，见 R2.5），不改变任何合法性判断。
* **调兵链深度**：链里已有 `MAX_QUEUE` 条就不再追加 —— 每刻只弹 1 条（R4.7），排太多会让指令迟到。

## 4. 可调参数

| 参数 | 默认 | 作用 |
| --- | --- | --- |
| `CAP_RESERVE` / `CAP_RESERVE_MAX` | 2 / 12 | 王城留守下限 / 上限 |
| `DEFEND_RADIUS` / `DEFEND_MARGIN` | 3 / 2 | 回防的警戒半径与余量 |
| `PROBE_MIN` | 2 | 向迷雾试探的最小兵力（视野外看不到守军） |
| `CITY_GOAL_STEPS` | 10 | 专门为城市行军的最大步数（0 = 只顺手拿） |
| `CITY_MARGIN` | 1 | 攻城时到达兵力比守军多的余量 |
| `MOPUP_LAND` | 16 | 对手地块数 ≤ 它则改为逐个拔点 |
| `CHIP_RATIO` / `CHIP_FRACTION` | 1.5 / 0.4 | 磨王城的兵力门槛与单次最小换血比例 |
| `PUSH_THEIR_FACTOR` / `PUSH_DIST_COST` / `PUSH_MARGIN` | 1.0 / 1.0 / 4 | 压向王城的门槛（系数 1.0 = 假设对手全部兵力都在王城） |
| `USE_HINTS` | 1 | 是否用"5×5 全非山"的王城候选块作为推进方向先验 |
| `MAX_QUEUE` | 2 | 调兵链里最多预排几条 |

子类覆盖这些类属性即可做离线参数锦标赛。

## 5. 离线评测（`tools/ai_arena.py`）

```powershell
# 自建基准：真实内核 + 真实校验路径，双座位各打一遍
.\.venv\Scripts\python.exe tools\ai_arena.py --a aegis --b greedy,sample-greedy --games 30 --swap
# 换对手 / 换长度 / 看明细
.\.venv\Scripts\python.exe tools\ai_arena.py --a aegis --b cosmos-apex --games 30 --seed0 3000 --swap --max-ticks 1400 --json out.json
```

每个 Tick 的驱动顺序与线上一致：两个座位先各 `act()` 一次并通过 `game.commands.enqueue_move`
（真人与 AI 共用的校验路径）入队，再 `tick.step()`。非法动作用 `rejects` 计，策略异常用 `errors` 计。

### 5.1 快照结果（2026-11-24，种子 3000–3029，地图边长 12–18，双座位各 30 局 = 每对手 60 局）

| 对手 | 600 Tick（300 回合） | 1400 Tick（700 回合） |
| --- | --- | --- |
| 内置 `greedy` / `sample-greedy` / `random` / `hold` | 60/60 全胜（4 个对手共 240 局，0 负 0 平） | 全胜 |
| `duel-general` | 57 胜 3 平 0 负（得分 0.975） | 30 胜 0 平 0 负 |
| `cosmos-apex` | 57 胜 2 平 1 负（0.967） | 29 胜 0 平 1 负 |
| `cosmos-lead-1v1` | 54 胜 5 平 1 负（0.942） | 30 胜 0 平 0 负 |

* 无非法指令（`rejects = 0`）、无策略异常（`errors = 0`）；本方单次 `act()` 最慢约 50 ms（预算 400 ms）。
* 边长逐个扫过 10–18（每档双座位各 2 局）：36/36 全胜，`rejects = 0`、`errors = 0`，单次决策最慢 34 ms。
* 中位取胜时刻：对内置策略约 130–160 回合，对上面三个策略约 180 回合。
* 300 回合封顶时剩下的约 2% 未结束对局，多数是"对手只剩山里死角"或双方都收不掉最后两格。
* 同仓库的 `cosmos-*` / `duel-general` 由其它会话并行迭代，强弱会变；上表只是当日快照。

## 6. 已知局限

* 视野只有"己方地块 ⊕ 8 邻"（R3.5），对手王城位置靠**实际探到**；找不到时会朝"王城候选块"
  方向推进，可能绕路。
* 5×5 全非山只是**概率性**先验（山占 20%、城占 4%），偶有误判；它只影响推进方向，不影响合法性。
* 兵力高度分散（占地所得）时，最后把兵汇到一点完全受"1 条/刻"限制，长盘会把时间花在汇兵上。
* 不预测对手的具体走法（只按"对手全部兵力都可能在我目标处"做最坏估计），因此偏稳、不赌。
