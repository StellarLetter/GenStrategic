# `ai/` — 策略目录（自动挂载）

把任何 `*.py` 文件放进本目录，**服务器启动时会自动加载**，无需修改服务端代码；
Web 界面的「策略」下拉框里立刻能看到它，可直接让某个玩家座位由它接管。

- 编写方法：见 [`docs/AI_API.md`](../docs/AI_API.md)（只读这一份就能写完一个策略）。
- 现成模板：`sample_greedy.py`（复制改名即可）。
- 重载：改完文件不必重启服务，调用 `POST /api/ai/reload`，或刷新页面时点「刷新策略」。
- 加载失败的文件不会影响服务器与其它策略：错误会显示在界面的策略面板与
  `GET /api/ai/strategies` 的 `errors` 字段里。
- 仓库发布约定：`ai/*.py` 被 `.gitignore` 排除，**只有 `sample_greedy.py` 入库**；
  自己写的策略留在本地、只随本机运行，不会出现在公开仓库里。

## 目录约定

| 路径 | 说明 |
| --- | --- |
| `ai/*.py` | 每个文件按独立模块加载；`_` 或 `.` 开头的文件被跳过 |
| `ai/<包>/__init__.py` | 子目录带 `__init__.py` 时整体作为一个包加载 |
| `ai/_*.py` | 不会被自动加载（放私人草稿/公共工具用；包内辅助模块可正常 `import`） |

同目录下的辅助模块可以直接 `import`（加载器会把本目录加入 `sys.path`）。

## 约束（与内置策略一致）

- 只读 `Observation`，只返回 `Action`；**永远不能**改写 `GameState`
  （AI 与真人使用完全相同的视野裁剪与指令校验，没有作弊通道）。
- 每个 Tick 至多提交 1 条调兵（R4.7）；比例只能取 10%…100% 十档（R6.6）。
- 策略实例**按座位独立创建**：不要把状态放在类属性上，放 `self` 上。
